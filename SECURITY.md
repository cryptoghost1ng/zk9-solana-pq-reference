# Security policy

This is an unaudited research snapshot. Do not use it with real funds. There is no bug bounty.

If you find a flaw — in the proofs, the parameters, the relay journal, the Solana programs' logic or anywhere in this snapshot — please report it privately to **GitHub's private vulnerability reporting for this repository (https://github.com/cryptoghost1ng/zk9-solana-pq-reference/security/advisories/new)** before discussing it in public,
and include the file, the commit of the snapshot (see `MANIFEST.json`) and, if you can, a reproduction. Reports about the parameter analysis in [CLAIMS.md](CLAIMS.md) are especially welcome: it is the author's
order-of-magnitude arithmetic and has not been reviewed by a cryptographer.

Out of scope: anything that requires running this against real funds, social engineering, and findings about third-party software (Plonky3, Solana, Tor, Chrome) that belong to those projects.
